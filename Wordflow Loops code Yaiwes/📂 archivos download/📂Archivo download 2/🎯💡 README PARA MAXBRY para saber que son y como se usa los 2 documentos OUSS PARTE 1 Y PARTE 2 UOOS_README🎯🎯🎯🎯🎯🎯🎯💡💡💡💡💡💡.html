UOOS · Sistema Operativo Documental
Readme — resumen de uso

Dos documentos.
Un sistema que se ejecuta solo.

UOOS es un par de especificaciones que convierten cualquier código o instrucción ya generada en un sistema orquestado, auto-ejecutable y determinista — sin que tengas que volver a explicar nada.

Claude te genera trabajo

02

Pegas UOOS Parte 1 (AUTO-RUN)

03

Guardas B1–B8 en /UOOS/

En el repo del proyecto, o los subes directo al agente ejecutor.

04

Pegas UOOS Parte 2 (RUNTIME) en Claude Code / OpenClaw

El agente hace boot, verifica integridad, y ejecuta el DAG nodo por nodo. Tú solo dices GO.

Las dos piezas

PARTE 1 · AUTO-RUN

El Arquitecto

Escanea el trabajo previo y lo convierte en especificación completa, lista para cualquier ejecutor.

  • Detecta MODO A (código) o MODO B (instrucciones)
  • Genera 8 bloques: Manifest, state, DSL, DAG, Loops, Tribunal, Plan, Recovery
  • Entrega uno por uno, con gate de aprobación
Se lo das a: Claude / Opus (Arquitecto)
PARTE 2 · RUNTIME

El Ejecutor

Lee B1–B8 como única fuente de verdad y ejecuta sin criterio propio, sin preguntar de más, sin desviarse.

  • Boot en 5 pasos: versión, integridad, preflight, skills, reanudación
  • Ciclo por nodo con Tribunal + verificación real del objetivo
  • 12 reglas estrictas que prohíben iniciativa y replanificación
Se lo das a: Claude Code / OpenClaw / agente

Cómo lo usas, paso a paso

Genera o ten listo el trabajo en un chat con Claude (código o instrucciones, no importa cuál).

Pega UOOS Parte 1 en ese mismo chat. No expliques nada más: el documento ya sabe qué hacer.

Aprueba bloque por bloque con OK, o pide un ajuste con FIX <detalle>.

Guarda los 8 documentos en /UOOS/ dentro del repo, o súbelos como archivos al agente ejecutor.

Pega UOOS Parte 2 como primer mensaje al agente ejecutor (Claude Code, OpenClaw, etc).

Espera el boot — el agente confirma 8/8 OK y te muestra el orden de ejecución.

Escribe GO y el agente ejecuta el DAG completo, nodo por nodo, sin pedirte nada que ya esté escrito en los documentos.

Comandos que necesitas saber

GOOKFIX <detalle> PAUSAESTADOSALTAR T-X UNLOCK <doc>ABORT
Regla de oro del sistema: si algo no está escrito en B1–B8, el agente debe preguntar — nunca inventar. Y si el Tribunal aprueba pero el objetivo del nodo no se cumple del todo, el nodo no se marca como terminado.
